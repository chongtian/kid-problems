### DynamoDB tables

**template:** DynomoDB-tables-template.yaml

Run this command to generate a CDK application for this template. The --from-path value is the name of the template file download.

```bash
cdk migrate --stack-name dynomoDB-tables --from-path ./dynomoDB-tables.yaml --language typescript
```
